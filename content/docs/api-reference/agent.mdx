# Agent

The `Agent` class defines an AI agent's identity, behavior, model provider, and available capabilities.

An Agent is a configuration object. It does not execute requests itself.

To execute an agent, use [`Runner`](/docs/api-reference/runner).

---

## Import

```ts
import { Agent } from 'agni-sdk';
```

---

# Constructor

Creates a new Agent instance.

```ts
new Agent(options);
```

---

## Parameters

### `options`

Configuration object used to create an agent.

| Parameter         | Type                      | Required | Description                               |
| ----------------- | ------------------------- | -------- | ----------------------------------------- |
| `name`            | `string`                  | Yes      | Name used to identify the agent           |
| `provider`        | `ModelProvider`           | Yes      | Provider responsible for model generation |
| `instructions`    | `string`                  | No       | System instructions passed to the model   |
| `tools`           | `Tool[]`                  | No       | Tools available during execution          |
| `providerOptions` | `Record<string, unknown>` | No       | Provider-specific options                 |

---

## Example

```ts
import { Agent, GeminiProvider } from 'agni-sdk';

const provider = new GeminiProvider({
  apiKey: process.env.GEMINI_API_KEY!,
});

const agent = new Agent({
  name: 'assistant',

  instructions: 'You are a helpful AI assistant.',

  provider,
});
```

---

# Agent with tools

Tools extend an agent's capabilities beyond text generation.

```ts
const agent = new Agent({
  name: 'weather-agent',

  instructions: 'Use the weather tool whenever the user asks about weather.',

  provider,

  tools: [weatherTool],
});
```

When a model requests a tool call, Agni's runtime handles:

1. Tool selection
2. Tool execution
3. Result injection
4. Final response generation

# Execution

Agents are executed using `Runner`.

```ts
const result = await runner.run(
  agent,

  'Explain how agents work.',

  {
    context: {},
  },
);
```

The Runner manages the complete lifecycle:

- Creating execution context
- Calling providers
- Handling tool execution
- Publishing runtime events
- Returning the final result
