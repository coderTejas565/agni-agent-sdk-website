# RunResult

`RunResult` is the normalized response returned by [`Runner.run()`](/docs/api-reference/runner).

Every agent execution produces a `RunResult`, regardless of whether the execution succeeds or fails.

It provides:

- Generated output
- Execution status
- Runtime metadata
- Error information

---

## Import

```ts
import type { RunResult } from 'agni-sdk';
```

---

# Type Definition

```ts
interface RunResult<T = string> {
  success: boolean;

  output?: T;

  error?: AgniError;

  metadata: RunMetadata;
}
```

---

# Example

```ts
const result = await runner.run(
  agent,

  'Explain AI agents.',

  {
    context: {},
  },
);

if (result.success) {
  console.log(result.output);
}
```

---

# Properties

## `success`

Indicates whether the agent execution completed successfully.

```ts
result.success;
```

**Type**

```ts
boolean;
```

Returns:

| Value   | Meaning                          |
| ------- | -------------------------------- |
| `true`  | Execution completed successfully |
| `false` | Execution failed                 |

---

## `output`

The final response generated by the agent.

```ts
result.output;
```

**Type**

```ts
T | undefined;
```

Example:

```ts
{
  success: true,

  output:
    "The weather in Pune is Sunny."
}
```

The output is available only when `success` is `true`.

---

## `error`

Contains execution failure details.

```ts
result.error;
```

**Type**

```ts
AgniError | undefined;
```

Example:

```ts
if (!result.success) {
  console.error(result.error);
}
```

Possible errors include:

- Provider failures
- Tool execution errors
- Runtime limit errors
- Validation failures

---

## `metadata`

Contains execution information generated during the run.

```ts
result.metadata;
```

**Type**

```ts
RunMetadata;
```

Example:

```ts
{
  runId:
    "a10bd101-6254-4d5b-bc03-b1272b7adda6",

  turns: 2
}
```

---

# RunMetadata

```ts
interface RunMetadata {
  runId: string;

  turns: number;
}
```

---

## `runId`

Unique identifier for the execution.

```ts
result.metadata.runId;
```

Use this value for:

- Logging
- Debugging
- Distributed tracing
- Observability systems

Example:

```ts
'a10bd101-6254-4d5b-bc03-b1272b7adda6';
```

---

## `turns`

Number of runtime turns completed.

```ts
result.metadata.turns;
```

**Type**

```ts
number;
```

A turn represents one complete agent reasoning cycle.

Example:

```
User Input

    |

    v

Provider

    |

    v

Tool Call

    |

    v

Provider

    |

    v

Final Response
```

This execution contains:

```ts
{
  turns: 2;
}
```

---

# Successful execution

Example:

```ts
{
  success: true,

  output:
    "The weather in Pune today is Sunny with a temperature of 29°C.",

  metadata: {

    runId:
      "2389c130-8624-4232-8c69-3dffadf4ac6d",

    turns: 2,

  }

}
```

---

# Failed execution

Example:

```ts
{
  success: false,

  error: {

    code:
      "PROVIDER_ERROR",

    message:
      "Unable to generate response."

  },

  metadata: {

    runId:
      "7c92d4d1",

    turns: 1,

  }

}
```

# Type-safe output

You can define custom output types.

```ts
type WeatherResponse = {
  city: string;

  temperature: number;

  condition: string;
};

const result = await runner.run<WeatherResponse>(
  agent,

  'Weather in Pune',

  {
    context: {},
  },
);
```

Now `result.output` is typed as:

```ts
WeatherResponse;
```

---

# Handling results

Recommended pattern:

```ts
const result = await runner.run(agent, input, {
  context: {},
});

if (!result.success) {
  throw result.error;
}

return result.output;
```

---

# Lifecycle

A RunResult is created after the runtime completes execution.

```text
Agent Created

      |

      v

Runner Executes

      |

      v

Provider / Tools

      |

      v

Execution Complete

      |

      v

RunResult Returned
```
