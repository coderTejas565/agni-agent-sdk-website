# RAG Agent

Retrieval-Augmented Generation (RAG) allows an agent to answer questions using your own documents instead of relying only on the language model's training data.

In a typical RAG workflow, the model does **not** search your documents directly.

Instead, it asks a retrieval tool for relevant context, and then generates an answer using that retrieved information.

---

## What You'll Build

A RAG agent that:

- Retrieves relevant document chunks
- Uses those chunks as context
- Generates grounded answers
- Avoids hallucinations

## Retrieval Tool

The retrieval tool is responsible for searching your knowledge base.

```ts
const retrieveTool = {
  name: 'retrieve_documents',

  description: 'Searches the knowledge base for relevant information.',

  parameters: {
    type: 'object',

    properties: {
      query: {
        type: 'string',
      },
    },

    required: ['query'],
  },

  async execute({ query }) {
    return await searchKnowledgeBase(query);
  },
};
```

The implementation of `searchKnowledgeBase()` depends on your storage layer.

It might query:

- Pinecone
- Qdrant
- PostgreSQL + pgvector
- Weaviate
- Chroma
- Any custom vector database

---

## Create the Agent

```ts
const agent = new Agent({
  name: 'rag-agent',

  instructions: 'Answer questions only using the retrieved context.',

  provider,

  tools: [retrieveTool],
});
```

Whenever additional knowledge is required, the model can call `retrieve_documents()`.

---

## Why RAG?

Without retrieval, an LLM can only answer using its training data.

RAG enables agents to work with:

- Internal documentation
- Product manuals
- Company knowledge bases
- PDFs
- Notion pages
- Wikis
- Support documentation

This makes answers more accurate, up-to-date, and grounded in your own data.

---

## Production Considerations

A production RAG system usually includes:

- Document ingestion
- Chunking
- Embedding generation
- Vector indexing
- Similarity search
- Prompt construction
- Citation support

Agni focuses on orchestrating the runtime. You can integrate any retrieval pipeline that fits your application.
