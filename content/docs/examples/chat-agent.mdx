# Chat Agent

This example demonstrates the simplest conversational agent you can build with Agni.

The agent:

- Receives a user message
- Sends it to an LLM
- Returns a response
- Uses no tools or memory

It is the ideal starting point for understanding the Agni runtime.

## Create the Agent

```ts
import "dotenv/config";

import {
  Agent,
  Runner,
  GeminiProvider,
} from "agni-sdk";

const provider = new GeminiProvider({
  apiKey: process.env.GEMINI_API_KEY!,
});

const agent = new Agent({
  name: "chat-agent",

  instructions:
    "You are a friendly and helpful AI assistant.",

  provider,
});

const runner = new Runner();

const result = await runner.run(
  agent,

  "Explain how JavaScript promises work.",

  {
    context: {},
  }
);

if (result.success) {
  console.log(result.output);
}
```

## What Happens Internally?

```text
User Message
      │
      ▼
Agent
      │
      ▼
Runner
      │
      ▼
Gemini Provider
      │
      ▼
Language Model
      │
      ▼
Text Response
      │
      ▼
RunResult
```

The Runner creates a new execution context, sends the conversation to the provider, waits for the model response, and returns a normalized `RunResult`.

Since no tools are registered, the runtime completes after a single provider call.
