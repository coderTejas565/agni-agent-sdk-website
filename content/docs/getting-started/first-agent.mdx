# Create your first agent

An Agni agent is built using three core primitives:

- **Agent** — defines what your agent is
- **Provider** — connects your agent to an AI model
- **Runner** — executes the agent lifecycle

Together, these components create a complete AI agent workflow.

---

The Runner controls execution while the Provider handles communication with the AI model.

## Create a provider

First, configure an AI model provider.

Agni keeps providers separate from agents, allowing your agent logic to remain independent from the underlying model.

```ts
import { GeminiProvider } from 'agni-agent-sdk';

const provider = new GeminiProvider({
  apiKey: process.env.GEMINI_API_KEY!,
});
```

---

## Define an agent

An Agent describes the behavior and purpose of your AI system.

```ts
import { Agent } from 'agni-agent-sdk';

const agent = new Agent({
  name: 'assistant',

  instructions: 'You are a helpful AI assistant.',

  provider,
});
```

The agent contains:

| Property       | Purpose                 |
| -------------- | ----------------------- |
| `name`         | Identifies your agent   |
| `instructions` | Defines agent behavior  |
| `provider`     | Connects to an AI model |

---

## Run the agent

The Runner executes the complete agent lifecycle.

```ts
import { Runner } from 'agni-agent-sdk';

const runner = new Runner();

const result = await runner.run(
  agent,

  'Explain how AI agents work.',

  {
    context: {},
  },
);

console.log(result.output);
```

The Runner handles:

- creating execution context
- sending requests to providers
- processing responses
- executing tools
- returning results

---

## Complete example

Here is the complete agent:

```ts
import 'dotenv/config';

import { Agent, Runner, GeminiProvider } from 'agni-agent-sdk';

const provider = new GeminiProvider({
  apiKey: process.env.GEMINI_API_KEY!,
});

const agent = new Agent({
  name: 'assistant',

  instructions: 'You are a helpful AI assistant.',

  provider,
});

const runner = new Runner();

const result = await runner.run(
  agent,

  'Explain how AI agents work.',

  {
    context: {},
  },
);

if (result.success) {
  console.log(result.output);
}
```

## Understanding the result

Every execution returns a normalized result.

Example:

```ts
{
  success: true,

  output: "AI agents are systems that..."

  metadata: {
    runId: "...",
    turns: 1
  }
}
```

The result contains:

### Success

Whether the agent completed successfully.

### Output

The final response generated by the agent.

### Metadata

Execution information such as:

- run ID
- execution turns

---

## What happens internally?

When you call:

```ts
runner.run(agent, input);
```

Agni:

1. Creates a runtime context
2. Sends the request to the provider
3. Receives the model response
4. Executes tools if required
5. Continues until completion
6. Returns the final result

This execution loop is the core of Agni.
