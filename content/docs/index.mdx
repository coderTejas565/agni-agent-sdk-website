# Build reliable AI agents with control

Agni Agent SDK is a TypeScript-first runtime for building production-ready AI agents.

It gives developers explicit control over:

- Agent execution
- Tool calling
- Model providers
- Runtime events
- Memory
- Guardrails
- Observability

Agni is designed around one principle:

> Agents should be predictable, transparent, and easy to debug.

## Create your first agent

An Agni application is built around three primitives:

### Agent

Defines your agent's identity, instructions, and capabilities.

### Provider

Connects Agni to an AI model.

### Runner

Controls the complete agent execution lifecycle.

```ts
import 'dotenv/config';

import { Agent, Runner, GeminiProvider } from 'agni-agent-sdk';

const provider = new GeminiProvider({
  apiKey: process.env.GEMINI_API_KEY!,
});

const agent = new Agent({
  name: 'assistant',

  instructions: 'You are a helpful AI assistant.',

  provider,
});

const runner = new Runner();

const result = await runner.run(
  agent,

  'Explain how AI agents work.',

  {
    context: {},
  },
);

if (result.success) {
  console.log(result.output);
}
```

## How Agni works

Agni separates the agent system into clear layers.

```
User Input

     |

     v

   Agent

     |

     v

  Runner

     |

 +-----------+

 |           |

Provider   Tools

 |           |

 +-----------+

     |

     v

 Final Result
```

The runtime manages execution.

Providers handle model communication.

Tools extend agent capabilities.

This separation keeps your application logic independent from AI providers.

## Why Agni?

Most agent frameworks hide the execution loop.

Agni keeps the runtime visible.

You can understand:

- when an agent starts
- when a provider is called
- when tools execute
- how results are produced

Because reliable AI systems require visibility.
